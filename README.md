# Plataforma de Gestão de Condomínios (CondominiosBenguiados)

Uma aplicação web robusta desenvolvida em Java (Jakarta EE) para simplificar e automatizar a gestão administrativa e financeira de condomínios.

Este projeto demonstra a implementação de uma arquitetura baseada em Java Enterprise, empacotamento através de ficheiros `.war` e contentorização para deployment na cloud.

## Funcionalidades Principais (Ajusta estas consoante o teu projeto)

* **Gestão de Frações e Moradores:** Registo detalhado de proprietários, inquilinos e respetivas frações.
* **Controlo Financeiro:** Gestão de quotas, emissão de recibos e acompanhamento de despesas do edifício.
* **Sistema de Ocorrências:** Portal para os moradores reportarem avarias ou problemas nas zonas comuns.
* **Painel Administrativo:** *Dashboard* centralizado para a administração do condomínio tomar decisões com base em dados atualizados.

## 🛠️ Tech Stack & Infraestrutura

* **Linguagem/Framework:** Java, Jakarta EE
* **Containerização:** Docker
* **Deployment:** Render (Cloud Platform)
* **Formato de Build:** `.war` (Web Application Archive)
